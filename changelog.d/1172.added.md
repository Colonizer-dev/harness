**The mothership can merge its own colonies' pull requests (merge steward).** An org can set `auto_merge` to `green` or `green+rebase` in Settings → Workspaces, with a merge method (squash by default) and delete-branch. Every few minutes, one GraphQL read per org decides each colony pull request: a green, clean one is merged (GitHub's branch protection is never overridden); a behind or conflicting one gets GitHub's update-branch, then its colony is resumed to rebase; a real failing check resumes the colony with the job's log tail, twice at most; and a pull request whose jobs all failed in seconds with no steps, or that GitHub flagged for billing or a spending limit, is marked `ci_blocked` with one banner per org instead of burning colonies. The workspace page lists each pull request's state with a **Merge now** button. Off by default. ([#1172])
