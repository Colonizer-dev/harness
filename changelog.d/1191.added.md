**The watchdog now fixes known stalls itself, and releases can install themselves.** A remediation playbook (signature, action, bounded tries; defaults compiled in, `playbook.toml` in the config directory to add or replace rows) answers a placeholder-dotfile denial, a `pr.md` write refused outside the repo and a toolchain-installer denial with the exact fix message, switches a colony held on `unrecognized_model` or provider quota to a healthy fallback and resumes it, and publishes an idle colony whose verification is confirmed. The same denial after its tries stops the colony with attention `looping`. Each fix is logged as `auto-fixed: <signature>`, listed on the session as `auto_fixes` and shown in the colony header; security holds are never released. A new `updates.auto_apply` setting (`off`, `when_idle`, `always`) installs a newer release on the update-check cadence, with `when_idle` waiting until the spare app slot is free. ([#1191])
