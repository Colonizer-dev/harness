**Setup no longer asks for the Stack again after every restart.** The image-pull status is held in memory, so it read `idle` after each restart and Setup showed "image is not cached" even with the image on disk. The mothership now checks the image cache at startup and before answering `GET /api/sandbox/pull`, reporting `cached` for an image that is already there. Setup shows "Checking the image…" while that state is unknown instead of asking, and the advisory rows (Stack, first launch, live map) no longer turn the Settings dot amber once the machine, GitHub and Claude rows are done. The Stack and live-map rows have a "Don't ask again", kept on the mothership in `setup.json` (`GET`/`PUT /api/setup`). ([#1200])
