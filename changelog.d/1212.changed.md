**One repository multi-select everywhere a setting takes repositories.** The Docs & README, merge train, dependencies and TypeScript loops, the org settings (close superseded PRs, colony merge requests) and a phone's repository filter now share a searchable dropdown: "All repositories", "All in <org>" and each repository as a checkbox, shown as removable chips, with "Add owner/name…" for repositories not known yet. The server accepts `owner` and `*` in every one of those lists (`never` takes no wildcard), documented in the Mothership API. ([#1212])
