**The cockpit chat can now act, and every change waits for your approval.** On Anthropic-wire models the chat is connected to the Colonizer tools: reads (colonies, questions, issues, loops, providers, model assignments, orgs, the activity log) run at once, and every write (stop, resume, publish, answer, launch, queue order, switch models, run a loop, apply an update) becomes an approval card showing the exact action in plain words, the dry-run diff where the API has one, and how many colonies, orgs and repos it reaches, with Approve, Edit and Reject. `POST /api/chat/approvals/{id}` settles each call exactly once and writes `chat.approve` or `chat.reject` to the activity log. Secret values, security-hold release and switched-off orgs are refused, and writes are rate-limited. ([#1217])
