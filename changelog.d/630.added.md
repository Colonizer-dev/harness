- **Codex, Grok Build and Hermes colonies can ask you questions.** Each module now registers a
  vendored MCP server (`mcp.mjs`) with its CLI, whose one `ask_user` tool turns a call into a
  `question` event on the runner's loopback bridge; the cockpit's answer comes back as the tool
  result and the turn continues (an interrupt or a turn end cancels a pending ask, per §2 the
  question is never also a `tool_call`/`tool_result`). Hermes only loads MCP servers with the
  optional `mcp` Python extra, so its colony image now installs hermes-agent with
  `pip install -e ".[mcp]"`. ([#630])
