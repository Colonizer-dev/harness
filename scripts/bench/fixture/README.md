# colonizer-bench

A tiny project the Colonizer bench runs its fixed tasks against. `npm test` runs Node's own test runner.

`src/greet.js` builds a greeeting. `src/cart.js` adds up a cart.

Every task in `scripts/bench/tasks.json` lands on this repository as an issue. Colonies work on those
issues; the bench scores the pull requests. Nothing here is meant to be useful software.
